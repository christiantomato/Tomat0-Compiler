TOMAT0 SYNTAX

A guide on syntax rules with examples.

### Data Types and Variable Declarations
There are currently 3 supported types:
- **int** (integers)
- **string** (strings)
- **bool** (booleans)

To declare a variable, you must state type and give an assignment.

ex.
```
int x = 1
string greeting = "hello"
bool empty = false
```

### No Delimeters

Multiple line statements are not allowed. A result of this is that no delimeters (such as a semicolon in java or c) have to be used.

ex. 
```
~ java, c, etc.
int x = 1; 

~ tomat0
int x = 1 
```

### Comments

You can write single line comments using the squiggly worm **~** called tilda

ex.
```
~ this is a comment
int x = 1
```

### Print Statements

You can print any of the supported data types to the terminal using the keyword **print**. You can pass in an expression for integers and booleans, but not strings. 

ex.
```
print("hello world") 
print(x + 2 * 3) 
print(3 > 10 & 3 < x)
```

### Main Function

The entry point is specified using the keyword **sprout** followed by a curly brace block. It must be concluded with the key phrase **harvest tomato** to signal the runtime end. 

ex.
```
~ entry point
sprout {
   int x = 1
   print(x + 1)

   ~ runtime end
   harvest tomato
} 
```

# Complete Keywords List
The following words are reserved and cannot be used for identifier names.
- **int**: Data type.
- **string**: Data type.
- **bool**: Data type.
- **func**: Function declaration keyword.
- **print**: Print statement keyword.
- **if**: If statement keyword.
- **while**: While loop keyword.
- **true**: Keyword for true boolean value.
- **false**: Keyword for false boolean value.
- **is**: Denotes equality. 
- **yields**: Return type keyword.
- **harvest**: Return keyword.
- **sprout**: Entry point keyword.
- **tomato**: Keyword used in runtime stops.
- **throw**: Keyword for immediate runtime kill.
