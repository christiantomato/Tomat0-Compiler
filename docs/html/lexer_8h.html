Detailed Description

Tokenizes the contents of the .tmt source file.

Responsible for conducting lexical analysis. The lexer will traverse through the contents of the .tmt file and "tokenize" the contents, acting as the first step in breaking up our contents into meaningful units that can be more easily parsed.
