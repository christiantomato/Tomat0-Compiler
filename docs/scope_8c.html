Looks up the desired symbol in all scopes.

Nested scopes can use symbols from higher level scopes, so when we look up a symbol, we must traverse all the way up to the global scope to look for it.

Looks up the desired symbol in only this scope.

Each individual scope cannot have duplicate variable names, so this function is used to make sure the symbol name doesn't already exist in this scope but its okay if it exists in higher scopes! (shadowing).
